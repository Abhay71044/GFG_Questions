<h2><a href="https://www.geeksforgeeks.org/problems/time-difference5528/1">Time Difference</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given the start time <strong>st</strong> and end time <strong>et</strong> of a race in the format <strong>hh:mm:ss</strong>. Return the time taken to complete the race.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> st = "13:50:45", et = "14:55:50"
<strong>Output:</strong> "01:05:05"
<strong>Explanation:</strong> The time gap is 1 hour 5 minutes and 5 seconds.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> st = "12:00:00", et = "24:00:00"
<strong>Output:</strong> "12:00:00"
<strong>Explanation:</strong> The time gap is of 12 hours.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>0 ≤ hh ≤ 24<br>0 ≤ mm ≤ 59<br>0 ≤ ss ≤ 59<br>|st| = |et| = 8</span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Strings</code>&nbsp;<code>Mathematical</code>&nbsp;
